# Requested exclusions — 2026-10-11

## Scope

The user requested removal of these 71 entries' random encounters and transformations while preserving scripted encounters. The runtime list is `PersonalExcludedForms` in `Core Mechanics/Lists and Banning.i7x`. It does not set the built-in ban flags, disable situations or remove extensions.

- Roaming combat and hunting filter all weighted candidate entries, including special additions. Fights explicitly selected inside a scripted situation remain available. Named `challenge` calls are unchanged, including calls outside a situation.
- Partial/full infections, sex/breast infection rules, shifting, full-body helpers and direct scripted mutation blocks reject new applications of listed strains to the player. Fixed exclusions survive clearing bans and character import.
- Vial collection, trading and quest hand-ins remain; drinking a listed strain is rejected before consumption. Moreau rejects excluded purchases before charging and skips excluded guarantees; Nermine's excluded transformation service is unavailable.
- NPCs, events, scene text, relationship/progression changes, loot and definitions remain. Existing imported body parts are not automatically reset.
- Only canonical names listed below are excluded; unlisted variants remain available.

## Practical limits

Retained scene text can still describe a transformation even when the corresponding body changes are suppressed. Form-dependent script branches retain their original prerequisites; no artificial quest unlocks are added. The modified source has not been compiled or played, so preservation is verified by source comparison only.
